# Scumpy — шаблоны решений математических задач на Python

**Scumpy** — учебный Python-модуль с заготовками кода для задач по линейной алгебре, аналитической геометрии и теории вероятностей. Он помогает получить шаблон решения, подставить данные своего задания и выполнить вычисления в Python или Jupyter Notebook.

**Основная особенность:** большинство функций возвращают **текст Python-кода**, а не готовый числовой ответ. Функции подбора вероятностных задач копируют заготовку в буфер обмена.

Исходный код находится в файле [scumpy.py](scumpy.py).

## Для чего нужен проект

Модуль собирает в одном месте повторяющиеся способы решения учебных задач: вычисление определителей, решение систем уравнений, поиск корней, построение распределений и расчёт числовых характеристик случайных величин.

Типичный порядок работы:

1. Выбрать функцию или найти шаблон по фрагменту условия.
2. Получить код решения.
3. Подставить матрицы, вероятности и другие исходные данные.
4. Добавить необходимые импорты и выполнить код.
5. Проверить результат и соответствие решения условию задачи.

## Установка и подключение

Инструкция ниже использует исходный файл и не требует опубликованного пакета на PyPI.

1. Скачайте `scumpy.py` и поместите его рядом со своим скриптом или ноутбуком:

   ```text
   project/
   ├── scumpy.py
   └── example.py
   ```

2. Установите зависимости модуля:

   ```bash
   python -m pip install sympy pyperclip
   ```

3. Для шаблонов с NumPy и SciPy установите дополнительные библиотеки:

   ```bash
   python -m pip install numpy scipy
   ```

4. Подключите модуль:

   ```python
   import scumpy
   ```

Для аннотаций вида `list[str]`, используемых в исходнике, требуется Python 3.9 или новее. Точные версии зависимостей в исходном файле не зафиксированы.

## Примеры использования

### Получение шаблона для определителя

```python
import scumpy

code = scumpy.Deter(1, "A")
print(code)
```

Функция вернёт строку с кодом:

```python
pretty_print(det(A))
```

Чтобы выполнить вычисление, нужно задать матрицу и импортировать используемые функции:

```python
from sympy import Matrix, det, pretty_print

A = Matrix([
    [1, 2],
    [3, 4]
])

pretty_print(det(A))
# Результат: -2
```

### Шаблон для метода Гаусса

```python
import scumpy

print(scumpy.gaussian_elim(1, "augmented_matrix"))
```

Полученный код вызывает `augmented_matrix.rref()`. Перед выполнением нужно определить расширенную матрицу системы и импортировать `pretty_print` из SymPy.

### Шаблон матричного уравнения AXB = C

```python
import scumpy

print(scumpy.MatrixEquations(1, "A", "B", "C"))
```

Заготовка использует выражение `A.inv() * C * B.inv()`. Для такого решения матрицы `A` и `B` должны быть обратимыми, а размеры матриц — согласованными.

### Поиск заготовки по условию задачи

```python
import scumpy

scumpy.rvs("В группе региональных банков имеется")
```

Если фрагмент соответствует одному из условий в исходнике, функция копирует связанный шаблон в буфер обмена. Его можно вставить в редактор через **Ctrl+V**, заменить исходные числа и добавить необходимые импорты.

Подбор основан на проверке вхождения строки в заранее записанные условия. Это поиск по тексту, чувствительный к формулировке и регистру, а не автоматический разбор произвольной математической задачи.

## Основные функции

| Функция | Назначение |
|---|---|
| `MatrixOps(...)` | Шаблоны операций с матрицами |
| `MatrixEquations(...)` | Шаблоны матричных уравнений |
| `Deter(...)` | Определители и условия вырожденности |
| `Permute(...)` | Матрицы перестановок и следы их степеней |
| `BigMatrices(...)` | Матрицы специальной структуры |
| `MatrixRows(...)` | Суммы степеней матриц и связанные выражения |
| `ComplexNumbers(...)` | Задачи с комплексными корнями |
| `Polynomials(...)` | Численный поиск корней многочленов |
| `gaussian_elim(...)` | Приведённая ступенчатая форма матрицы |
| `gaussian_elim_parameters(...)` | Ступенчатая форма для задач с параметрами |
| `EigenValsAndVects(...)` | Собственные значения и векторы |
| `Cartesian(...)` | Геометрические задачи на плоскости |
| `arrayy(...)` | Подсказка о выборе функции по тексту условия |
| `rv_discrete(...)`, `rvs(...)` | Выбор вероятностной заготовки и копирование в буфер обмена |

В функциях с параметром `num` он выбирает вариант шаблона: нумерация начинается с **1**. Количество вариантов зависит от функции. Имена матриц в ряде функций передаются строками, например `"A"`, поскольку вставляются в генерируемый код.

Функция `scumpy.rv_discrete` — собственный подборщик шаблонов. Она отличается от `scipy.stats.rv_discrete`, которая создаёт дискретное распределение. Чтобы не смешивать одноимённые функции, удобно использовать явный импорт `import scumpy`.

## Что реализовано

В одном модуле собраны шаблоны математических решений, для части задач предложено несколько вариантов. Реализованы генерация кода с подстановкой параметров, подбор заготовок по фрагментам условий и копирование в буфер обмена.

В исходном файле нет отчёта о тестировании, измерений производительности или подтверждённых показателей корректности. Результат проекта — коллекция учебных заготовок, качество которых следует проверять для конкретных входных данных.

## Особенности текущей версии

- Во многих вероятностных шаблонах исходные числа зафиксированы в коде: их необходимо заменить данными своего задания.
- Часть заготовок использует переменные и импорты, которые пользователь должен определить самостоятельно.
- Некоторые возвращаемые строки содержат поясняющий текст; перед выполнением его нужно отделить от Python-кода.
- Неизвестный фрагмент условия в `rvs` или `rv_discrete` может привести к ошибке: обработка отсутствия совпадения не предусмотрена.
- Функция `arifm_and_geom_matrix_progression` формирует строку без `return`, поэтому сейчас возвращает `None`.
- Есть повторяющиеся блоки и ограничения на размерность матриц в отдельных шаблонах.
- Работа с буфером обмена зависит от окружения; в удалённых ноутбуках и средах без графического интерфейса она может быть недоступна.
